# Boilerplate Gaps & Opportunities

## Observations & Recommendations

1. **Path Alias Resolutions**: Required adding `@src/*` alias resolution in `tsconfig.src.json` and Vite configuration for seamless IDE imports.
2. **Built-in OTP Auth Provider**: Extending Wasp auth DSL to natively support phone number + OTP auth methods out of the box would further eliminate custom OTP table management.
3. **PWA Offline Support**: Future enhancements could include ServiceWorker caching for offline slot viewing in low-connectivity areas.
