# Strip UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert BSAM into a backend-only Wasp application by removing every current UI artifact while preserving database, auth, server operations, and tests.

**Architecture:** `main.wasp.ts` remains the sole Wasp application spec and registers only database seeding, authentication, queries, and actions. The React source tree, browser routes, UI tooling, static UI asset, and UI-only dependencies are removed; server code under `src/server/` is untouched.

**Tech Stack:** Wasp 0.24.0, TypeScript, Prisma, Vitest, npm.

## Global Constraints

- Preserve `db.seeds`, the complete `auth` block, and every existing server `query(...)` and `action(...)` registration in `main.wasp.ts`.
- Do not alter `schema.prisma`, migrations, or any file under `src/server/` other than generated outputs from verification (which must not be committed).
- Do not install `@wasp.sh/spec` from npm; retain its `file:.wasp/spec/` dev dependency.
- Delete all current browser pages, React components, UI styles, UI build configuration, and UI-only static assets.
- Validate Wasp changes with `wasp compile`; do not use `tsc` directly as the Wasp validity check.
- Use a separate worktree and the subagent-driven workflow for execution.

---
